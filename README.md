# Meme雷达

Meme雷达是一个在 Windows 本地运行的 Web 工具，用于发现 Robinhood Chain 上 Pons 与 Uniswap 的新 Meme 交易池，进行基础热度/风险筛选，并可监控指定 X KOL 的公开帖子。

项目只提供信息整理和提醒，不连接钱包、不自动交易、不记录仓位，也不构成投资建议。
