# Meme雷达用户验收标准

## 阶段1：链上核心

- 双击安装脚本能够完成环境检查、依赖安装和数据库初始化。
- 双击启动脚本后网页自动打开，页面显示扫描中或明确的配置错误。
- Pons与Uniswap的新池事件能够被去重保存。
- 机会页、全部新币页、手动分析页、设置页和币种详情页可正常打开。
- 数据不足时显示“未知/数据不足”，不会发出机会提醒。
- 达到默认条件的固定测试样本被分类为重点关注；高风险样本不会发送机会通知。
- 浏览器关闭而后台运行时仍可发送Windows测试通知。
- 停止脚本只停止本项目，不影响其他Python程序。
- 7天过期数据可以自动和手动清理，配置不会被删除。

## 阶段2：X与KOL

- 可以添加、暂停和删除最多10位KOL。
- X开启时按5分钟间隔增量获取新帖子，不重复处理同一帖子。
- 合约地址匹配标为已确认；同名多币不会被自动选择。
- 详情页可显示近24小时提及数和代表帖子链接。
- X总开关关闭后，自动任务、手动刷新和所有X网络请求均停止；重启后仍保持关闭。
- 暂停或关机期间的数据不会补采。
- 本地费用估算达到80%时警告，达到100%时暂停X请求。
- 测试使用模拟响应，不消耗真实X额度。

## 阶段3：稳定与交付

- 连续运行24小时后无重复通知风暴、数据库持续增长异常或后台进程泄漏。
- RPC断开、API限流和单一来源故障不会导致整个软件崩溃。
- 日志、网页和Git历史中没有API密钥或完整授权头。
- 安装、启动、停止和卸载脚本在干净Windows环境完成一次端到端验证。
- 卸载只删除本项目生成的文件，不卸载系统Python或影响其他程序。
- README和用户指南足以让非技术用户完成安装、配置、启动、暂停X、停止和卸载。
